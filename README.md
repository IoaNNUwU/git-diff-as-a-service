# git-diff-app

### Запуск

1. Создать `.env` файл (шаблон - `.env.example`)
2. `make env/up` - запуск БД (необходим для корректной работы приложения)
3. `make migrate/up` - создание коректной схемы БД
4. `make run` - запуск приложения

### Интеграционные тесты

1. `make env/down` - остановка рабочей БД
2. `make test/env/up` - запуск отдельной БД для тестирования (без томов, полный ресет при каждом перезапуске)
3. `make test/migrate/up` - создание коректной схемы (необходим при каждом перезапуске)
4. `make run` - запуск приложения (оно теперь будет использовать тестовую БД)
5. `make test` - запуск в отдельном терминале `HTTP` клиента, который делает запросы к основному приложению и тестирует ответы.

# Фичи

## Авторизация

1. POST `/auth/register` - создание нового пользователя и сессии для него по логину паролю и доп информации.
2. POST `/auth/login` - открытие сессии для пользователя по логину и паролю.
3. DELETE `/auth/logout` - закрытие текущей сессии.

## Файлы

1. POST `/files` - создание нового файла для текущего пользователя.
2. DELETE `/files` - удаление файла, если текущий пользователь владеет им.

# Особенности

- Фича `files` требует авторизацию, реализовано через `middleware`. При отсутствии куки `session_id` возвращается статус `Unauthorized`.
